# 群雄戦線 / Unreal Engine版

開発先は **Unreal Engine 5.7**。`GunyuTactics.uproject` が編集用プロジェクト。ルートの旧Siv3D版とは別に開く。戦闘ルールを共通C++ライブラリへ分け、表示、入力、演出と素材はUEで作る。

出会い→軍議→HEX戦闘→戦後→次の軍議を同じ進行状態で遊ぶ序章。武将と命令をクリックし、連鎖の順序と成立予測を見ながら操作できる。隊列・旗・武将肖像・戦法カットイン・移動と押し返し・損害表示・効果音を接続済み。兵士と地形は簡易モデルで、完成版の美術・BGM・仕官先選択・長期の歴史進行は未対応。序章の進行は「記録 / F6」から保存・再開できる。

## Gitから復元する

Unrealの `.umap` と `.uasset` は、ルートの `.gitattributes` に従い **Git LFS** で保存する。ソース、設定、素材の元画像・音声、マップ、取り込み済み素材を管理対象にし、`Binaries` / `Intermediate` / `Saved` / `DerivedDataCache` は再生成する。プレイ中の個人セーブはGitには含めない。

別のPCではGit LFS、UE5.7とC++ビルド環境を入れ、次の順に実行する。GitHubのZIPダウンロードより、LFSを有効にしたcloneを使う。

```powershell
git lfs install
git clone https://github.com/sei-26/Sangokushi.git
cd Sangokushi
git lfs pull
& ./Unreal/Tools/build.ps1
& ./Unreal/Tools/register_project.ps1
& ./Unreal/Tools/launch.ps1 -Editor
```

`Tools/build.ps1` のVisual Studio / EngineRootは使用するPCに合わせる。初回は共通ルールのライブラリとUEモジュールのビルドが必要なので、先にbuild.ps1を実行してから `.uproject` を開く。保存済みの `Content/Maps/TacticalTrial.umap` と素材があるため、通常の復元でbootstrapや素材生成をやり直す必要はない。`git lfs ls-files` でUE素材が一覧に出ることを確認できる。

## 開き方と編集

Epic Games Launcher → Unreal Engine → ライブラリ → マイプロジェクト → **GunyuTactics**。一覧が更新されない場合はLauncherを開き直すか、`GunyuTactics.uproject` を直接開く。エンジンは5.7を選ぶ。

1. 最初に開く `/Game/Maps/TacticalTrial` が試作戦場。上部の「再生」で操作する。
2. ワールドアウトライナーの **Tactical Field - select to edit Trial settings** を選ぶ。
3. 詳細の `Trial / Scenario` で `First Mission`（0:突破、1:護送、2:防衛）と最初の `Enemy Policy`（0:追撃、1:固守、2:偵察）を変更できる。`Start With Council` は通常オン。オフにすると従来の戦闘直行の検証起動になる。任務を直接開く場合は新しい資源状態から開始する。
4. `Trial / Art` で地面・味方・敵・樹木・目的地のマテリアルと、樹冠・岩・草・鎧・兜・盾・門の屋根のモデルを差し替える。地面のマテリアルは頂点カラーを使うと地形種別と視界の色が残る。マップに配置したライトと霧も編集できる。
5. 保存して再生。C++のビルド直後は、編集中の内容を保存してエディタを閉じてから再ビルドする。

ゲームだけを遊ぶ場合は **`Play.cmd` をダブルクリック**する（内部で `Tools/launch.ps1` を実行）。デスクトップ解像度のボーダーレス・フルスクリーンで起動する。エディタ内の再生サイズは変更しない。終了は `Alt+F4`。明示的な `-windowed` 起動と描画検証ではフルスクリーンを強制しない。

`Trial / Presentation` の `Playback Speed`（0.5〜2倍）と `Effects Volume`（0〜1）で演出速度・効果音量を調整できる。

現時点のHEX配置と勝利条件は共通C++側の `NewGame/JourneyMission.hpp`、入力・仮の描画は `Source/GunyuTactics/`。地形を自由に彫ったLandscapeとルール上の地形を同期する編集機能は次の工程。

## 試作の操作

最初は劉備・関羽・張飛との会話。「話を聞く」を押して軍議へ進む（`Enter` も使用可能）。史実背景と創作の会話・局地戦を画面で区別する。

最初の軍議で「退路を開く」か「避難車まで送り届ける」を選ぶ。通常起動の初期案は避難車の護送。護衛600・兵糧900を追加し、季安の避難車を６区間先の東の出口へ送る。期限は10指揮。先鋒を崩すだけでは終わらず、味方で車道を塞いでも停止する。退路確保案は従来の勝利条件と期限８指揮を使う。

軍議と戦後では３人へ個別に話しかけられる。実際の護送と撤収の結果に応じて反応が変わり、会話の繰り返しで絆は増えない。季安を送り届けた場合は次の任務の糧車も季安が担う。各戦の約束の結果と帰還兵・損失は軍議と終幕に残る。参照元と改善の狙いは [STORY_STRATEGY_IMPROVEMENTS.md](../STORY_STRATEGY_IMPROVEMENTS.md)。

軍議では「伏兵の段取り」（通常の士気、準備済み伏兵を試みる）か「兵糧を厚くする」（士気100、携行兵糧増、伏兵は別途準備）を選ぶ。準備の選択だけでは資源を使わず、出陣時に表示した兵・兵糧・軍資金を実際に支払う。護送の積荷と護衛の費用も含む。「義勇兵1,200を募る」は軍資金250・兵糧500を払い、軍議につき１回だけ実行できる。

勝敗が決まると、損耗や連鎖の成果に応じた会話と、帰還兵・野営地の資源・武将同士の絆を表示する。勝利後は自動で出陣せず、実際の残兵と物資を持った次の軍議へ進む。敗北後の「軍議に戻って再挑戦」は、その戦い直前の状態を復元する。前の任務の成果や募兵費用を複製せず、その戦いの準備を選び直せる。アプリ終了後も「記録 / F6」から保存・再開できる。

- 下部の武将カード、味方部隊、または `1 / 2 / 3` で選択。カードに兵・士気・行動済み・潜伏を表示。見えている敵を左クリックすると右欄の対象が切り替わる。敵味方は名札・旗・足元のリングでも区別する。
- 右の「移動先を指定」→水色の隣接マスをクリック。右クリックによる直接移動も可能。通常攻撃・伏兵準備・固守も右のボタンで指示する。
- 「誘導を連鎖に予約」→水色の後退先を選ぶ。続いて関羽の伏兵、張飛の突破を予約。最大３手、各武将１手。`↑ / ↓` で順序変更、「取消」で１手を外す。成立見込みと停止理由が更新され、予測される位置変化は金色の矢印で表示される。
- **１手だけでも「単独戦法を発動 / C」で発動できる**。最大３手、成功順に火力100％→125％→150％。誘導・支援も成功コンボに数え、攻撃戦法の兵損耗を強化する。別の発動は１から開始。森林での伏兵準備、敵の隙・混乱・低士気は追加威力や状態効果につながる。義勇の誓いは自隊にも届き、鼓舞は次の攻撃で使うまで持続する。[詳細](../TACTIC_COMBO_UPGRADE.md)。
- 「連鎖を発動」で発動。下部に各手の結果を残す。途中停止した場合、未実行の手と武将の行動権を残して現在の配置で再判定する。誘導だけで停止すると隣接した伏兵が露見することがある。露見後も急襲は可能だが、準備済み伏兵の威力と混乱効果は失う。士気不足・射程外・押し出し先の閉塞など、実際の停止理由を確認しよう。
- 最初は「連鎖の見本」→「予約した連鎖を実行」で３手を試せる。先鋒を弱らせ、必要なら「次の指揮へ」から残る攻撃・突破で崩す（開始設定が突破・追撃の場合）。避難車の護送を約束した場合は、その後も車の進路と護衛を守る。
- 右上の「深追いを止め、撤収する」を押し、もう一度「撤収を決める」で任務を中止する。`Esc` や別の命令で確認を取り消せる。実際の生存兵と残りの糧を回収し、勝利や護送完了の実績は付かない。戦後には各武将の反応を確認し、軍議から準備を見直せる。
- 「次の指揮へ」で敵行動と次の指揮。未実行の予約がある場合は、破棄して進める操作をもう一度押す。`Esc` で取消。勝利後は「戦果を引き継いで次へ」で次の軍議へ進む。最初の敵方針はエディタ設定、後続の敵方針は共通ルールの任務進行に従う。
- 矢印キーでカメラ移動、ホイールでズーム、`Home` で全体表示。`N` はエディタで設定した開始任務と初期資源へリセットする。アプリ終了後も「記録 / F6」から保存・再開できる。

補助キー: `M` 移動先選択、`A` 伏兵準備、`G` 固守、`F` 通常攻撃。劉備選択中の `Q` / 関羽の `W` / 張飛の `E` で戦法予約、`T` 見本、`C` 発動、`R` 全取消、`Space` 次の指揮、`Enter` 勝利後の次任務、`Esc` 対象指定の取消。

UE側も敵の表示・対象指定・予測には観測済み情報を使う。未発見の実座標を表示しない。攻撃・固守・兵糧・勝敗は元のルールへ委譲し、別の戦闘計算を増やさない。

戦法が使えないときは右の予約欄の上に理由を表示する。固有使用済みは戦法▼から通常戦法へ切り替える。確認中の敵がいなければ攻撃戦法は予約できず、護送任務は車を出口まで送る。対象が失われた後は、見えている別の生存敵へ選択だけを更新し、既存の予約対象は変えない。[詳細](../TACTIC_AVAILABILITY_FIX.md)。

序章の第１・第２戦の勝利後は、主人公として次の戦いの約束を２つから選び、その後に次の軍議へ進む。返答だけで信頼は増えず、次戦の実結果で劉備・関羽・張飛の反応と主人公への信頼が変わる。個別信頼は出陣士気にも反映する。軍議・戦後は顔付きの掛け合いをスクロールして読める。[仕様・人物の声](../BATTLE_STORY_UPGRADE.md)。

## 城郭と遠景

北側の城郭・街並み・二層の山並みを追加。`K` は標準・臨場・俯瞰・遠景の４種類を切り替える。遠景から標準へ戻すと以前の焦点へ戻る。Trial / ArtのFortress MaterialとDistant Materialで素材を変更できる。城郭は現在の任務の目標とは別の背景。[編集箇所・再現手順・20検証群](../FORTRESS_BACKDROP_UPGRADE.md)。

## 行動を伝える演出

[CORE_DESIGN.md](../CORE_DESIGN.md) の「何が起きてなぜ起きたかを伝える」を基準に、戦闘結果を１回だけ計算し、その実結果を順に描画する。演出で追加ダメージや成功判定を作らない。

- 誘導は囮の後退→敵の追撃、伏兵は接近と混乱、突破は前進と敵の押し出しを表示する。各手は標準３秒。
- 発動する武将の肖像・戦法名・実際の理由を上部に表示し、命中時に兵数と損害表示を更新する。失敗した手では停止理由を表示し、その先の攻撃を再生しない。
- 通常移動・攻撃・固守・伏兵準備・敵指揮も演出する。敵指揮は観測した開始位置と終了位置の補間であり、敵の内部経路を再現するものではない。
- 演出中は追加命令を受け付けない。`Space` / `Esc` または「演出を完了」で確定結果まで飛ばせる。予約の予測と、実行中の損害を区別して表示する。
- 護送任務の糧車は歩兵と異なる荷車の形で表示する。戦場外の装飾地面や土煙は、地形判定・視界・移動可能範囲を変えない。

兵の腕・脚を関節でつなぎ、行軍・槍の突き・被弾・固守の姿勢を描画する。指揮の一時停止で動きも止まる。代表兵は最大48体／部隊。[動作の範囲と検証](../INFANTRY_MOTION_UPGRADE.md)。

部隊札に現在の行動と段階を表示し、担当は金色、被弾は橙色で示す。足元の向きと観測済みの対象にも小さな目印を出す。待機・潜伏などは部隊ごとに残り、カードと対象欄にも反映する。[表示範囲と22検証群](../BATTLE_ACTIVITY_UPGRADE.md)。

青龍偃月の広い斬光、大喝の圧力の波、味方中心の誓いを、異なる視点と短い光の強調で見せる。連鎖の終盤には次の予約担当の顔と名前を表示。Oでカットイン・自動視点・カメラの光の強調を切り替えられる。[演出の範囲と検証](../TACTIC_SPECTACLE_UPGRADE.md)。

連鎖の再生後は **Y / 伝令欄の「戦法記録」** で、直近の各手の役割・実損害・つながり・停止理由を確認できる。戦後からも開ける。閲覧でリアルタイムの指揮を停止し、閉じた後も停止を保つ。記録は既存のセーブから読み直せる。[使い方と25検証群](../CHAIN_REVIEW_UPGRADE.md)。

## AI素材の取り込み

`ArtSource/manifest.json` に元ファイル、UE内の保存先、素材名、出典を記録する。既存のオリジナル武将肖像３枚を取り込み済み。劉備・関羽・張飛は旧版の `PortraitCatalog.hpp` と同じ人物対応・切り出し範囲を使い、武将カード・部隊名札・カットインに表示する。

エディタの **ツール → Pythonスクリプトを実行** から `Tools/import_art.py` を実行する。標準では既存アセットを上書きしない。更新取り込みは環境変数 `GUNYU_REIMPORT_ART=1` を指定した場合だけ行う。

AIで作った肖像・背景・テクスチャをこの手順に追加し、マテリアルやUIから参照する。3Dモデルの造形・リグ・アニメーション、テクスチャの法線・粗さ・継ぎ目は別途制作・調整が必要。

## 再ビルド・再現

このPCではUE5.7.4、Visual StudioのMSVC14.44を使用。ビルドスクリプトのVisual Studioパスは現在のPC向け。他の環境では `Tools/build.ps1` の `$vsRoot` を変更する。

リポジトリのルートから:

```powershell
& .\Unreal\Tools\build.ps1
```

初回または生成済みContentがない環境では、次を順に実行する。生成スクリプトは既存マップ・素材グラフを保持し、必要な描画フラグと未接続の頂点カラーだけ補修する。

```powershell
$editor = 'C:\Program Files\Epic Games\UE_5.7\Engine\Binaries\Win64\UnrealEditor-Cmd.exe'
$project = (Resolve-Path .\Unreal\GunyuTactics.uproject).Path
$bootstrap = (Resolve-Path .\Unreal\Tools\bootstrap.py).Path
& $editor $project -run=pythonscript "-script=$bootstrap" -unattended -nullrhi
$importer = (Resolve-Path .\Unreal\Tools\import_art.py).Path
& $editor $project -run=pythonscript "-script=$importer" -unattended -nullrhi
$presentation = (Resolve-Path .\Unreal\Tools\prepare_presentation.py).Path
& $editor $project "-ExecutePythonScript=$presentation" -RenderOffscreen -unattended
& .\Unreal\Tools\register_project.ps1
& .\Unreal\Tools\launch.ps1 -Editor
```

`-game -GunyuSmoke -nullrhi -unattended` でUE内の個別予約・予測の非破壊性・並べ替え・途中停止後の行動・未実行予約の破棄確認・移動・勝利から護送への接続を確認する。終了コード0とログの `GUNYU_RULES_SMOKE: PASS` の両方を確認する。

`-game -GunyuCapture -windowed -ResX=1600 -ResY=900 -RenderOffscreen` は `Saved/trial.png` を撮影して終了する。追加の `-GunyuPlan` は見本予約、`-GunyuMove` は移動先選択状態の描画確認用。

`-GunyuCinema -CueTime=4.7` を撮影オプションに追加すると、見本連鎖の4.7秒地点を静止して確認する。`GUNYU_PLAYBACK: PASS` は手ごとの損害、移動補間、入力制限、スキップと自然終了の一致、失敗時の停止、観測情報での敵表示の結合検証。

`-GunyuCouncil` は最初の軍議、`-GunyuDebrief` は通常の命令で最初の戦いに勝利した戦後画面を撮影する。`GUNYU_JOURNEY: PASS` は会話から軍議、募兵の一度限りの支払い、準備の選択、敗北と再挑戦、３戦の通常操作による完遂、資源と絆の引き継ぎ、終幕の結合検証。

`-GunyuWithdrawal` は撤収後の画面、`-GunyuGuan` / `-GunyuZhang` は軍議・戦後の話し相手の選択。`GUNYU_PROMISE: PASS` は実費を伴う作戦の約束、３人の会話、撤収と取消、精算の一度限りの実行、再挑戦、新しい護送任務の通常命令での完遂、次戦へ帰ってくる季安の検証。

`Tools/prepare_presentation.py` は不足している演出素材と、独自に合成した３種類の効果音を作成する。元WAVは `ArtSource/Audio/`、UEアセットは `Content/Audio/`。短い音はPCMを使用する。既存マテリアルは上書きしない。追加素材の作成には音声機能が初期化される通常エディタのPython実行を使う。
