# 📊 CSVデータ編集ガイド

## 🎯 概要

このゲームは **CSVファイル** でシナリオデータを管理します。
ExcelやGoogleスプレッドシートで編集して、**プログラムを実行するだけで反映**されます。

---

## 📁 ファイル構成

```
プロジェクトフォルダ/
├── cities.csv      # 都市データ
├── officers.csv    # 武将データ
└── Main.cpp        # ゲーム本体
```

---

## 🏯 cities.csv（都市データ）

### 列の説明

| 列名 | 説明 | 例 |
|---|---|---|
| 都市名 | 都市の名前 | 許昌 |
| 所有者 | 支配している勢力 | 曹操 |
| X座標 | 画面上のX位置 (50-1500) | 450 |
| Y座標 | 画面上のY位置 (50-850) | 450 |
| 兵数 | 初期兵力 | 8000 |
| 金 | 初期資金 | 3000 |
| 兵糧 | 初期兵糧 | 5000 |
| 農業 | 農業値 (収穫に影響) | 80 |
| 商業 | 商業値 (収入に影響) | 90 |
| 兵舎 | 兵舎レベル | 70 |
| 治安 | 治安 (0-100) | 85 |
| 勢力色 | 勢力の色 (16進数) | #4169E1 |

### 色の指定方法

Excelで色を選んで、16進数コードをコピーしてください。

**主な色の例：**
- 青: `#4169E1` （曹操）
- 赤: `#DC143C` （袁紹）
- 緑: `#32CD32` （劉備）
- 紫: `#9370DB` （劉表）
- 金: `#FFD700` （袁術）
- オレンジ: `#FF8C00` （その他）

## 👤 officers.csv（武将データ）

### 列の説明

| 列名 | 説明 | 例 |
|---|---|---|
| 武将名 | 武将の名前 | 曹操 |
| 所属勢力 | 所属する勢力 | 曹操 |
| 配置都市 | 初期配置される都市 | 許昌 |
| 統率 | 統率力 (0-100) | 95 |
| 武力 | 武力 (0-100) | 85 |

### 注意点

- **配置都市**は cities.csv に存在する都市名にしてください
- **所属勢力**はその都市の所有者と一致させてください

---

## ✏️ 編集方法

### 1. Excelで開く

1. `cities.csv` をExcelで開く
2. データを編集
3. **CSV UTF-8形式**で保存

### 2. 新しい都市を追加

1. 最後の行に追加
2. すべての列を埋める
3. 座標は他の都市と重ならないように

### 3. 新しい武将を追加

1. `officers.csv` に追加
2. 配置都市が存在するか確認

### 4. 勢力を追加

1. cities.csv で新しい所有者名を指定
2. 新しい色を指定
3. その勢力の武将を officers.csv に追加

---

## 🎮 実行方法

1. CSVファイルを編集
2. CSVを保存
3. **ゲームを起動するだけ**

→ 自動的にCSVが読み込まれます！

## 💡 Tips

### 座標の決め方

画面サイズは **1600 x 900** です。

- 左端: X=100
- 右端: X=1500
- 上端: Y=100
- 下端: Y=800

### バランス調整

**強い勢力：**
- 兵数: 8000以上
- 金: 3000以上
- 武将の統率・武力: 90以上

**弱い勢力：**
- 兵数: 3000以下
- 金: 1500以下
- 武将の統率・武力: 70以下

---

## ⚠️ トラブルシューティング

### ゲームが起動しない

→ cities.csv と officers.csv がプロジェクトフォルダにあるか確認

### 都市が表示されない

→ CSVの形式が正しいか確認（カンマ区切り、UTF-8）

### 武将が配置されない

→ 配置都市名と所属勢力が cities.csv と一致しているか確認
