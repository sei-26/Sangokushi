# 群雄戦線 オリジナルBGM

ゲーム用に作曲・合成した6曲のループ音源です。既存作品の曲や録音サンプルは使用していません。金管・弦・笛・撥弦・太鼓・銅鑼を模した合成音によるインストゥルメンタルで、生演奏の録音ではありません。

| ファイル | 曲名 | 使用場面 |
| --- | --- | --- |
| a-continent-under-banners.wav | 大陸に旗を掲げよ | 本編の平時 |
| battle-of-the-burning-river.wav | 紅蓮の決戦 | 本編の交戦・英雄譚の決戦 |
| banner-of-dawn.wav | 黎明の旗 | スタート・桃園・終章の導入 |
| companions-road.wav | 仲間と歩む道 | 仲間との旅・内政の章 |
| bridge-in-the-storm.wav | 嵐の橋 | 長坂の導入・敗北 |
| oath-carried-forward.wav | 誓いを明日へ | 勝利・結末 |

22,050Hz・ステレオ・16bit PCM WAV。合計約20MiB。実行時に必要な曲だけストリーミングで読み込みます。各曲は16小節で、曲間は1.4秒のクロスフェード。カットイン中はBGMを抑えます。

再生成: Python 3 と NumPy を使ってリポジトリルートから `python tools/build_story_music.py` を実行してください。固定シードで同じ順番に6曲を生成し、`manifest.json` に長さ・ピーク・RMS・ループ端の差を記録します。

同名のWAVを差し替えるとゲーム内でも置き換わります。BキーでBGMのON/OFF、Nキーで音量20/40/60/80%、Mキーは効果音です。音量の選択は起動中に保持されます。
