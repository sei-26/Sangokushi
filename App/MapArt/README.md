# 新しいマップ素材

ゲームから読む素材。OpenAI内蔵の image_gen ツールで新規生成したオリジナル画像を、生成元からこのディレクトリへコピーしている。

- `terrain-atlas-v1.png`：4列×2行。上段は山4種、下段は森2種・城・府。透過PNG。
- `ground-materials-v1.png`：2列×2行。草地・土・川・海。地形の六角形にUVを割り当てて描画する。

地形と進路の計算は既存のマスを使う。素材は見た目だけに適用し、欠落時は従来の手続き的描画に戻る。画像の読み込み・素材選択・配置は `NewGame/CampaignMapArt.hpp/.cpp` に分離。山と森は地図キャッシュへ奥から手前に描画し、都市と府は表示倍率に合わせて描画する。
