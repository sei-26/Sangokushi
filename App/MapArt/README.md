# 新しいマップ素材

ゲームから読む素材。OpenAI内蔵の image_gen ツールで新規生成したオリジナル画像を、生成元からこのディレクトリへコピーしている。

- `terrain-atlas-v1.png`：4列×2行。上段は山4種、下段は森2種・城・府。透過PNG。
- `ground-materials-v1.png`：2列×2行。草地・土・川・海。地形の六角形にUVを割り当てて描画する。

地形と進路の計算は既存のマスを使う。素材は見た目だけに適用し、欠落時は従来の手続き的描画に戻る。画像の読み込み・素材選択・配置は `NewGame/CampaignMapArt.hpp/.cpp` に分離。山と森は `CampaignSceneTerrain.cpp` で表示範囲のみ奥から手前に描画し、元画像の縦横比を維持する。山・森・都市・府は表示倍率に合わせて素材から直接描画する。

## 自然な地形の描画
山・森林の透過素材 `terrain-relief-v2.png` を追加。内蔵image_genで新規生成し、生成元からプロジェクトへコピーしています。プロンプトは [TERRAIN_V2_PROMPT.md](TERRAIN_V2_PROMPT.md)。城・府は既存atlasを継続利用。

山の隣接数から大きい主稜線と小さい支稜線を配置し、形・大きさ・位置を変えます。地面と水面のUVは世界座標から連続して割り当て、マスごとのランダムな模様の切り替えをなくしました。川岸は複数の薄い色を重ねます。地面・水面のキャッシュは1マス48px。草地・土・川・海は読み込み時に別テクスチャへ分け、8マス周期の連続UVと異方性フィルタで描画する。山・森はキャッシュの拡大を経由せず、元素材から画面へ直接描画するため、ズームしても小さい中間画像によるぼやけや縦横の変形が発生しない。

Tキー・左の表示ボタンで自然地形 / 領土色を切り替え。初期表示は領土色（地形を残す薄い塗り）で、勢力は境界線・都市の色・凡例から読めます。領土色モードでは従来の強い塗りを使います。ゲームの地形分類・通行・射線・補給の計算は共通です。


## 山麓・林縁・水際のつながり
森林と山の分布から地面の色を補間し、林縁の緑と山麓の岩肌をなだらかに重ねます。この処理は地図の更新時だけキャッシュへ描画し、カメラ移動時には再計算しません。隣り合う山は素材の形と大きさをそろえ、同じ形の連続には変化をつけます。森林同士の隙間には小さな樹群、平野との境目には疎らな木を描画。元素材の縦横比と直接描画を維持しています。

川岸と海岸は共有する端点を維持した曲線と段階的な色で砂浜・浅瀬を表示。海に沿う太い勢力境界は描画せず、内陸の勢力境界を維持します。進軍ルートは山・森の上に描画します。通行判定・地形効果・勢力所有・セーブのデータは共通です。プレビュー `terrain-detail` は倍率6、`terrain-coast` は東岸の確認用です。


## 水面と都市周辺の景観
川には隣り合う水域に沿って動く光の筋、海にはゆっくり移動して消える波のきらめきを追加。都市の近くの平野には小道・農地・集落を描き、農業値が高い都市は農地が増え、都市規模が高いほど周辺の家も増えます。小道は景観用で、兵站・移動速度の効果はありません。橋・武将・進軍ルート・地名の読み取りを優先します。装飾は地図キャッシュ、水面の動きは表示範囲のみの描画です。


## 中国全土の全国図
`china-atlas-v1.png` は参考画像の褐色の地形表現を参考に、内蔵image_genで新規生成した背景。生成元の画像をそのままコピーし、縦横比を維持して描画します。都市・紋章・名前・勢力色・進路はゲーム側の描画で重ねます。プロンプトは [CHINA_ATLAS_PROMPT.md](CHINA_ATLAS_PROMPT.md)。描画は `CampaignSceneAtlas.cpp`、表示座標は `ChinaAtlas.hpp`。背景は地理の概略表現で、戦場の通行判定には使いません。
