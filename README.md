# 三国志シミュレーション

C++ / OpenSiv3D 0.6.16で制作している三国志シミュレーション。

現在の起動先は新作の戦略試作「群雄戦線」。全土のマス上で行軍・野戦・攻城・領地占領・補給を扱う。都市の農政・商業・治安・兵站に武将を任命し、30日かけて発展させる。24武将の政治・得意分野を活用でき、速度切替・一時停止・1日送りでじっくり進められる。操作と仕様は [NEW_GAME.md](NEW_GAME.md) を参照。

「武将・評定」から個性・知力・魅力・親密度を確認し、共同内政・停戦交渉・敵都市への工作を任せられる。部隊ごとの戦法を手動で発動でき、プレイ中の出来事は「群雄の記録」に残る。歴史ストーリーモードは今後の追加要素。

以前の作品「志在千里 ～三國志正伝～」は新作メニューの「以前の作品を開く」から起動できる。

## 開発・起動

- `Sangokushi.sln` をVisual Studioで開き、x64でビルドする。
- OpenSiv3D 0.6.16のSDKと環境変数 `SIV3D_0_6_16` が必要。
- 実行時の作業ディレクトリは `App`。ビルド後の実行ファイルもここにコピーされる。
- Debugはデバッグ情報をオブジェクト内に保持してPDBマネージャー不一致を避ける。Releaseは同梱Siv3Dライブラリに合わせた静的ランタイムを使用する。

## ファイルの役割

| 場所 | 内容 |
|---|---|
| ルートの `.cpp` / `.hpp` | ゲームの処理と画面 |
| `NewGame/` | 新作のシミュレーション・保存処理・画面 |
| `App/cities.csv` / `App/officers.csv` | 都市・武将の初期データ |
| `App/cities_3.csv.xlsx` | 都市データの編集用資料 |
| `App/Audio/` | BGM・効果音 |
| `App/engine/` / `App/dll/` | Siv3Dの実行用資源・ライブラリ |
| `App/Resource.rc` / `App/icon.ico` | 埋め込み資源・アプリアイコン |
| `App/save*.json` | プレイ中のセーブ |
| `Intermediate/` / `.vs/` / `App/AS_DEBUG/` | ビルド・開発時の生成物 |

武将プレイの操作は [CAREER_PLAY.md](CAREER_PLAY.md)、領地の開拓は [TERRITORY_PLAY.md](TERRITORY_PLAY.md)、シナリオデータの編集は [CSV編集ガイド](App/CSV編集ガイド.md) を参照。

## 整理したもの

ゲームから参照されていなかった `App/example/` のSiv3Dサンプル素材、旧画面 `WorldMapScene.h` / `GameClearScene.hpp`、ビルド対象外で参照されていなかった `Unit.cpp`、過去の警告修正メモを削除した。プロジェクトとフィルターの登録も更新した。

実行用のエンジン資源、音声、シナリオデータ、編集資料、セーブは保持している。
