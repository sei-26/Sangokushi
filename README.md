# 群雄戦線

C++で制作している三国志シミュレーション。2026-10-21、ユーザーの決定により **Unreal Engineへ開発先を変更**。「敵の判断を読み、戦場の状況を仕込み、武将たちを動かして、自分が狙った勝ち方を成立させる」をコアに、作戦の実行から歴史のIFを楽しむゲームを目指す。

**これから編集するUEプロジェクトは [Unreal/GunyuTactics.uproject](Unreal/GunyuTactics.uproject)**。UE5.7で開く。起動・エディタの編集箇所・操作・AI素材取り込みは [Unreal/README.md](Unreal/README.md)。現在は既存の戦闘ルールを接続した仮の3D戦場に、クリックでの個別命令、移動候補、連鎖の並べ替えと成立予測を実装。以下の旧UI・音楽・物語・全国戦略はSiv3D版の現状説明で、UE側への移植は順に進める。

UE版は `Unreal/Play.cmd` でフルスクリーン起動。武将との出会いから、軍議での準備・募兵、演出付きの戦闘、戦果に応じた会話、残兵と兵糧を引き継ぐ次の軍議へ進む。敗北後はその戦い直前の軍議から再挑戦できる。序章３戦の通常操作による完遂を検証済み。「記録 / F6」から手動３枠と軍議・戦後の自動記録を使える。経路・合図・観測と再挑戦用の資源も引き継ぐ。詳細は [JOURNEY_SAVE.md](JOURNEY_SAVE.md)。

「龍の軍師」を参考に、最初の軍議で守る約束を選び、実在する避難車を護送するルートを追加。送り届けた季安が次戦の糧車を担い、護送・撤収の結果に応じて劉備・関羽・張飛それぞれの会話が変わる。参照原稿と、物語・戦術の課題を同じ仕組みで改善する方針は [STORY_STRATEGY_IMPROVEMENTS.md](STORY_STRATEGY_IMPROVEMENTS.md)。

2026-10-14に設計方針を更新し、ドラマチックな歴史の流れの中で、主人公が仕える勢力を選び、その軍師として戦う一つの本編を目指す。[４枚仕様と実装状況](STRATEGIST_SPEC.md) を基準に制作する。現在は黄巾の乱を背景に、出会い・軍議・戦法連鎖・戦果を引き継ぐ３戦を遊べる。勢力選択、全国内政との接続、その先の歴史と保存は今後の実装。

最初はスタート画面上段の「本編序章 ― 軍師の第一策」を選ぶ。軍議で「伏兵の段取り」「追撃を好む敵」を採用し、戦場の「見本を予約」→「連鎖を発動 / C」で、誘導→伏兵→突破を試せる。自分で各武将の戦法を順に予約することもできる。Spaceで敵の手番、右クリックで通常移動、ホイールでズーム、中ボタンで地図移動、Homeで全体表示。戦果と資源は次の軍議へ返る。メニューに戻った間は進行保持、アプリ終了後の保存は未対応。詳しくは [CHAIN_BATTLE.md](CHAIN_BATTLE.md)。

スタート画面の「戦術検証 / 渡河・兵糧護送」で、軍議・部隊への個別命令・護送・戦果を試せる。45日以内に兵糧3,500以上を届け、戦闘兵7,500以上を温存する。敵は10日間の集結後に進軍。名簿で部隊を選び、右クリックで進路、右側の命令で輸送出発・待機・後退・構えを設定する。Spaceで10日進行、進行中はSpaceで閲覧の一時停止、Escでメニューへ戻る。創作の検証戦場で、保存は行わない。

軍師戦役の第2段階では、通常は偵察と目撃情報で敵情を判断する。暗い土地は監視外、「?」は過去の目撃。Pキーまたは「作戦設定 / 合図・後退」で、指定日・味方到着・敵確認による開始、兵数・士気・期限による中止と後退先を設定できる。偵察は視界を広げ、固守で行軍して攻撃力を半減させる。全情報公開は軍議で選ぶ比較用モード。単独戦役の保存と、全国の自由戦略への観測制限は今後の接続。

自由戦略では96×64マス・30都市の地図で行軍・野戦・攻城・領地占領・補給を扱う。武将の個性、戦法、共同内政、外交、謀略、親密度による連携が作戦に影響する。「武将配置」で人材を前線へ送り、任用先を整えてから遠征できる。速度切替・一時停止・1日送りでじっくり進められる。

ストーリーモード「英雄譚 ― 劉備の旗」では、全6章の会話、選択、内政、訪問、護衛戦、戦闘を通じて英雄の歩みを追体験する。史実・演義・ゲームの創作を区別して表示する。

コードを読む入口は [CODE_GUIDE.md](CODE_GUIDE.md)。処理は内政・外交・補給・戦闘・画面ごとの.cppに分けている。

## 開発・起動

ルールだけをSiv3Dなしでビルド・テストするCMakeターゲットも追加した。エンジンの変更範囲と動作確認は [ENGINE_REVIEW.md](ENGINE_REVIEW.md) を参照。

- Sangokushi.slnをVisual Studioで開き、x64でビルドする。
- OpenSiv3D 0.6.16のSDKと環境変数 SIV3D_0_6_16が必要。
- 実行時の作業ディレクトリはApp。ビルド後の実行ファイルもここへコピーされる。
- Debugはデバッグ情報をオブジェクト内に保持する。Releaseは同梱Siv3Dライブラリに合わせた静的ランタイムを使用する。
- tests/run.ps1で自由戦略、広域地図、英雄譚、保存と旧形式の互換性を検証する。
