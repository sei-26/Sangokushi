# 群雄戦線・4枚のコア企画書

[PowerPointを開く](群雄戦線_コア企画書_20261126_v2.pptx)

2026-11-26時点の現行UE本編を根拠にした、編集可能な4枚の資料。

1. **作品の目的**：英傑と策を交わし、自分の一手で歴史を動かす。歴史をもっと知りたくなる体験を届ける。
2. **判断の面白さ**：広宗で北の左翼を救うか、中央を突破して本隊を通すか。実際のゲーム画面で示す。
3. **主人公がいる意味**：勝ち方に人物が応え、救って生還させた兵の案内が、救援した武将の次戦の配置と士気へ返る。
4. **実装と完成像**：今遊べる戦役・戦法・自動戦闘と、自由な勢力加入や長編の構想を分ける。

画像は既存プロジェクトの主人公・劉備の会話素材と、実際のUnrealの広宗開戦画面。完成予想画面を実装の証拠にはしていない。出典ファイルと条件は各ページの発表者ノートに記載。本文はPowerPointで編集できる文字、画像は埋め込み。

検査：4枚・16:9、ファイル構造、文字の範囲、承認したNoto Sans JPフォント、Artifact Toolによる再読込を検証。全ページを画像化して確認。PowerPointアプリでの実操作テストとは区別する。

生成元は `tools/presentations/build_core_pitch.mjs`。引数はリポジトリ、ランタイム依存ルート、Presentationsスキルの絶対パス。`Intermediate/core-pitch-build/node_modules` をランタイムのNodeパッケージディレクトリへ接続してから実行する。再生成時は最終出力の名前に新しい日付または版を付け、既存の検証済みファイルを上書きしない。実画面の入力は `Intermediate/command-read-core-opening/Saved/trial.png`。この一時キャプチャはGitへ含めず、画像を埋め込んだ企画書を保存する。

企画の評価基準は「策を選べた。戦場が変わった。あの武将と、次の戦いへ行きたい」。これは制作上の仮説で、初見ユーザーの試遊結果としては扱わない。
